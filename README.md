# Machine Learning with Python

A collection of Jupyter notebooks for practicing machine-learning workflows with Python. Topics include classification, clustering, model evaluation, dimensionality reduction, and regularization.

## Notebooks

| Notebook | Topic |
| --- | --- |

| [Evaluating_Classification_Models.ipynb](Evaluating_Classification_Models.ipynb) | Evaluating classification models |
| [Evaluating_K-means_Clustering.ipynb](Evaluating_K-means_Clustering.ipynb) | Evaluating k-means clustering |
| [Evaluating_RandomForest.ipynb](Evaluating_RandomForest.ipynb) | Evaluating random forest performance |
| [KNN_lab.ipynb](KNN_lab.ipynb) | K-nearest neighbors classification |

| [Rainfall_Prediction_Classifier.ipynb](Rainfall_Prediction_Classifier.ipynb) | Rainfall prediction classifier (notebook is currently empty) |

## Running the notebooks

Open a notebook with Jupyter Notebook or JupyterLab, choose a Python kernel, and run its cells in order. Install any dependencies requested by the notebook in that environment. Dataset setup and requirements may vary between notebooks; check each notebook for its instructions.
